负责人：Codex。范围：主输入区 intent/chat/reply 的客户端持久请求与恢复；不改变后端模式、原生 Adapter、队列暂停、会话绑定或数据库 Schema。

## 已实现

- HTTP 前保存确切请求键、路径和内容；断线后保留，用户核对后恢复同一逻辑请求。
- 收到 API 结果后耐久保存，再结束本地请求。编辑过的草稿不会替换旧请求。
- 多窗口恢复绑定用户看到的原记录；预览 K1 后记录换成 K2 时停止，不能发送或消费 K2。
- 同一作用域跨进程发送锁覆盖 HTTP 和结果落盘；请求次数在 HTTP 前保存，旧创建者票据不能误把不确定请求清除。
- 不自动重发原生 UNKNOWN；API 请求确认、原生收件和任务完成仍分别显示。
