# UX-001 验收清单（含强制补充）

版本UX-001＋Product Experience Constraints 001，2026-11-12。负责人Codex。MAG-001 ACTIVE不改。以下为待执行验收，不是完成声明；Phase0事实见UI_CURRENT_STATE.md。

## 冻结的七项

- [ ] 三栏主工作台，顶部克制，普通交流为主区域。
- [ ] 项目/会话导航清楚，独立历史、接收者、草稿不串线。
- [ ] 消息时间线易读，回复/引用/来源可达，技术详情按需。
- [ ] 统一输入支持多行、明确接收者、已有文件材料引用和发送。
- [ ] 右侧上下文可折叠；仅当前会话；不因折叠丢掉异常提醒。
- [ ] 常见自然语言真正进入既有业务动作；不支持时明确未执行。
- [ ] 必要状态透明，逐目标异常可定位与查看原因。

## 补充一：不形成配置系统

- [ ] “让DSH独立检查这个修改”在对象唯一且信息齐全时直接安排，不要求重复填写类型/轮次/工作流。
- [ ] 有多个修改/任务时只问必要对象，不从上下文猜。
- [ ] 复用当前任务、材料版本、负责人/范围，不把已知字段重新表单化。
- [ ] 不可靠/超范围意图明确说明未执行，保留输入；没有虚假Task ID或“已安排”。
- [ ] 引用、代码、历史及普通姓名提及不能扩大接收范围；没有对象不发。
- [ ] 常见任务、复核、状态查询、总结请求、正式审查发起具备真实结果核对；总结请求不被冒称平台自行完成语义总结。

## 补充二：不隐藏工程事实

- [ ] 在线/模拟可用/暂停/未绑定/未知分别显示；后台连接不冒称Agent在线。
- [ ] 已排队、发送中、已提交、确认收到、回复/任务完成分别显示，不跨级推断。
- [ ] UNKNOWN显著标为待核对且不自动重发，不能显示成功。
- [ ] 收到任务≠正在处理≠已完成；没有对应回执显示尚未确认。
- [ ] 本机材料校验≠上传≠完整收件；版本不一致与缺失文件清晰提示。
- [ ] 人工报告≠VERIFIED；模拟验证始终标明模拟。
- [ ] 审查结果、P0/P1阻断、待用户授权方便发现；审议通过≠授权实施。
- [ ] 正常聊天简洁，技术详情可达；异常不能仅藏在折叠日志中。

## 补充三：范围与交付

- [ ] 仅七项主工作台目标；没有后台重写/Runtime/记忆/Social/Studio/完整桌面迁移。
- [ ] 新想法单独登记问题、收益与成本，不自动阻断本次交付。
- [ ] 一个负责人、一名必要复核者，原则两轮；P2/P3不无限阻断。
- [ ] 已验收布局不因纯偏好重新推翻。

## 安全、保留与证据

- [ ] 普通赞同不构成正式审批；用户决定不能替代Agent票，不自动授予真实实施权限。
- [ ] 项目/会话隔离、来源/版本、引用回复、转交、任务、审批、材料、审计回归。
- [ ] 回复Agent消息默认选择原作者，允许手动改对象；原作者不可用时停止，不自动转给其他人。
- [ ] 引用用户自己的消息保留当前接收对象，不因此广播或向自己投递。
- [ ] 暂停不改变；原三会话零操作，DSH草稿零读写；不启动/修改凪。
- [ ] 窗口切换、后端断开重启、重复请求、用户输入和草稿恢复不丢失/不重发。
- [ ] 低频旧能力有明确可达位置，未可靠自然化的功能保留备用入口。
- [ ] 实际WPF截图与运行验证；编译、静态检查、模拟、真人观察、真实Adapter严格分开。
- [ ] 首次使用测试由真正未用过产品者完成；没有真人观察不自称通过。
- [ ] 回滚入口可用；不修改主库结构、不破坏旧桌面与历史。
