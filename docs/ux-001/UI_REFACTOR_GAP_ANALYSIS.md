# UX-001：差距与最小改造边界

Task TRB-UX-001；负责人Codex；MAG-001不改；补充约束与主任务同等强制。

| 目标 | 核对现状 | 本轮最小改造 |
|---|---|---|
| 三栏工作台 | 项目树＋主区两栏，多排管理按钮 | 保留导航，中区对话，新增可折叠上下文栏 |
| 对话优先 | 卡片边框/状态重复；8项操作常驻 | 正文、身份、时间为主；回复/更多按需；异常仍明显 |
| 统一输入 | 多行输入＋单独接收者列表；@正文不解析 | 合并输入区接收者提示、附件引用、简洁发送；引用与草稿不丢 |
| 自然语言协作 | Send仅chat/reply，无意图执行接口 | 最小增量接口＋上下文解析，调用既有正式动作；不支持则明确未执行 |
| 状态透明 | 低层状态多，但未形成当前任务/材料摘要 | 摘要区分排队、提交、确认、完成；异常定位到原证据 |
| 上下文面板 | 任务、包、意见散在不同页 | 当前会话关联摘要，跳转已有详情；折叠时保留异常提示 |
| 原生桌面 | WPF已存在 | 在现有WPF内渐进改造；不另建桌面迁移项目 |
| 功能保留 | 56个命名按钮直接挂事件 | 先建立替代命令/更多入口，再移走重复按钮；后端不删 |

## 自然语言执行差距

1. 缺少“输入意图→上下文对象→现有API动作→真实执行结果”的接口。不能把显示“已安排”当执行。
2. “这个修改”必须绑定选中的材料/当前唯一任务及版本，不能只凭最后一句话猜。多个候选时仅问一个必要对象问题，不把已知参数重填成表单。
3. 初期支持范围应明确：已知对象的任务委派、指定一名复核者、状态查询、讨论总结请求、明确的正式审查发起。先复用已有动作；没有适合的正式动作不得用chat冒充。
4. “条件成立后再邀请第三方”的可靠语义和条件调度当前未实现。不能仅匹配人名即承诺自动执行；需要明确说明未安排的部分，不顺便重建复杂讨论引擎。
5. 审议/用户授权是不同状态。“这个方案不错”只是聊天；“我正式批准”也必须绑定当前对象/版本/权限，不得替Agent补投票或跳过必要审查。
6. 自然定向只能解析用户当前输入的明确指令，引用/代码/历史/@提及不触发。前端解析产生正式recipient_ids，由后端按原权限检查；不改为后端全文关键词广播。
7. 现有GovIntent是结构化治理核对入口，不是已经实现的通用自然语言调度器。自然风险判断和来源完整性不能用关键词自称可靠。

## 状态呈现必须有证据

| 事实 | 可以显示 | 不能推断 |
|---|---|---|
| 后台健康 | 本机后台已连接 | 三个Agent均在线 |
| SUBMITTED/SENT | 已提交，等待确认 | Agent已收到/完成 |
| UNKNOWN | 投递待核对，不自动重发 | 成功或可放心重试 |
| 请求确认 | 请求已确认，等待回复 | 模型正在思考或任务已完成 |
| 工程包本机校验通过 | 本机材料完整性通过 | 目标Agent已拿到完整版本 |
| 用户报告附件已发 | 用户报告已发送 | 原会话完整性VERIFIED |
| 模拟字节校验 | 模拟接收校验通过 | Hermes/DSH/ChatGPT真实收到 |
| 审查通过 | 指定版本审议通过 | 用户授权实施 |
| 等待用户验收 | 待你验收 | 已交付/已实施 |

收到任务、处理中、完成分别需要对应回执/任务事件；没有证据显示“尚未确认”，不制造活跃状态。材料版本不一致、P0/P1、需要授权、暂停、后端断开不藏进技术日志。

## 技术风险与控制

- WPF事件依赖固定x:Name及Button类型。直接改成MenuItem会空引用；ContextMenu独立名称域也不能依赖Win.FindName。应先建立显式命令映射，再搬控件。
- 四个Tab按索引硬编码，材料/治理刷新依赖索引2/3。改轻量导航必须先去除或兼容索引耦合。
- 两秒轮询异步竞态、Epoch、工作区草稿及选中消息必须保留；不能让切换后迟到请求覆盖其他会话。
- 当前StateLabel按事项汇总投递并重复到消息，重构必须保留逐目标详情，不能用绿色总状态掩盖一个UNKNOWN。
- 读取材料可能较大，不可在每个轮询为右栏重复读取全文件；右栏使用现有元数据，全文按需。
- 当前脚本与csproj清单有差异；新UI构建要验证实际运行，不只修改一个未使用项目文件。
- 原程序窗口可能仍打开。用独立候选exe/XAML、虚构库和单独启动入口验证，不覆盖运行中旧exe、不终止其他窗口。
- DPI、键盘、窄窗、长中文/代码仍需实际WPF验证。首次陌生用户体验无法由实现者自测替代，最终报告单列待用户组织验证。

## 不扩大范围

本轮不改Runtime、记忆、真实Adapter、主库架构、MAG制度、真实会话附件、不做完整原生迁移。条件调度、复杂语义、托盘通知等发现后只登记独立建议，不作为当前七项交付的隐含前置。
