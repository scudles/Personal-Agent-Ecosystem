# UX-001：实施计划与冻结范围

Task ID：TRB-UX-001。工程负责人：Codex /root，风险L2（跨WPF呈现与增量意图接口）。必要复核：用户已经授权的同一名只读Codex独立实例；不冒充ChatGPT Observer，不操作原会话，不默认三方。正式审查原则两轮；P2/P3记录而不阻断。

## 已采纳的产品约束

1. 自然语言不是配置系统。系统复用当前项目、会话、选中消息/任务/材料及已知风险和负责人。仅缺失、歧义或权限时简短提问；不得把常见请求改成多项配置表单。尚不可靠的意图返回“未执行＋原因”，不得虚报成功。
2. 隐藏噪声，不隐藏事实。异常便于发现，正常状态简洁，技术证据可展开。UNKNOWN≠成功；提交≠收到≠完成；上传≠完整性校验；审批≠实施授权。
3. 本阶段仅冻结七项：三栏、项目会话导航、消息时间线、统一输入、可折叠上下文、自然语言协作入口、必要状态透明。达到清单即可交付，不以更优雅或新增高级功能反复返工。

## Phase 0：本轮已执行

核对实际WPF、全部56命名按钮、后台动作、构建方式、状态与草稿依赖；生成CURRENT/COMPONENT/GAP/PLAN及独立验收清单。保留现状前台截图及源码哈希。本阶段不改变UI、API、Schema、真实绑定或投递。

## Phase 1：主工作台

新增独立候选UX窗口布局；基于现有应用类与BridgeClient。左侧项目/会话树，中区时间线＋固定输入，右侧可折叠上下文。顶部仅标题、项目/会话、必要状态、设置、窗口管理。低频管理进入更多/设置，暂停易找到。命令映射保留所有旧动作，修改前先处理x:Name与Tab索引依赖。

优先布局：左侧约230、右侧约280逻辑单位；中间随宽度扩展，正文合理最大宽度。窄窗时自动折叠右栏且可手动开关，不遮挡发送及异常。具体阈值以实际WPF 100%/125%/150% DPI验证，不把设计值写成已验证结论。

验收：创建/切换项目与会话、保留接收者和草稿、无串线；旧功能有新位置。交付可运行独立候选和实际截图。

## Phase 2：消息与输入

正文、发言者、时间、必要状态优先；正常细节按需。回复默认原作者，可手动改；转交保留来源。输入区统一多行、接收者、附加已有材料/知识引用、发送及引用提示。现有系统没有真实通用附件上传，不能画一个假上传按钮。

按投递目标显示当前必要状态，UNKNOWN/失败/取消/暂停可见并能查看原因；原始文本不改写。选中、复制、长文本、键盘操作、历史与自动刷新回归。每阶段实际截图。

## Phase 3：自然语言协作入口

仅新增小型意图接入层和WPF响应呈现，调用既有后端状态机，不重建工作流。数据隔离、幂等、预算、暂停、审查与授权继续在后端检查。

处理顺序：识别用户当前有效指令→从当前scope、选中对象及已有元数据解析→校验权限/MAG→具备信息则直接执行既有正式动作→返回真实ID/状态和证据链接。不能可靠解析返回未执行；缺失信息只追问所缺的一项。解析结果、澄清和执行失败都不清空用户草稿，不静默降级成成功聊天。

最小覆盖用例：向Hermes委派已有上下文的文字任务；让DSH对选中材料/任务独立复核；按MAG说明第三方是否需要；查询当前任务状态；定向请求总结；对明确材料发起正式审查。复杂条件链须明确能力边界。普通赞同不触发审批。正式用户决定仍单独记录、绑定版本，不能补Agent投票。

自然定向与显式接收者统一成正式recipient_ids。普通名字、引用、代码、历史不触发路由。不存在明确接收对象时不投递。上下文对象冲突时简短澄清，不从多个任务中猜一个。

在自然入口实际可用并通过安全回归前，任务/正式审批/修订等备用入口仍可通过“更多”访问；不通过删除能力换取简洁。

## Phase 4：上下文面板

仅当前会话相关的参与者、任务、材料版本、必要审查/阻断/授权信息；可折叠，折叠不隐藏全局异常。链接到保留的完整页面。收到、处理中、完成依证据分别显示；未知明确未知。模拟标签始终明确，不借后台健康推断原生Agent在线。

## Phase 5：统一与适配

WPF资源统一字体、间距、色彩、边界、焦点与禁用态。不大改业务。测试1920×1080、1366×768、可用窄窗，DPI100/125/150%，长中文、长代码、键盘与可读性。截图记录实际覆盖；未测尺寸单列。

## Phase 6：集成交付

使用虚构项目＋模拟Adapter。沿用原有有意义回归，增加意图执行/歧义/引用不路由/普通赞同/状态区分与跨窗口草稿测试。独立复核只覆盖变更与验收，原则最多两轮。首次使用者测试需真正未用过产品的人；没有观察结果不声称通过。真人测试未执行时，与已完成工程验证分别报告，不把技术验收伪装成用户体验验收。

每阶段报告新增/修改文件、原因、复用模块、已运行与静态检查/模拟的区别、失败与遗留、回滚和实际截图。当前七项完成并满足约定验收后正常交付，额外建议独立登记。
