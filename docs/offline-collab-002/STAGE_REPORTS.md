# 已实现能力与待验收边界

Task：TRB-OFFLINE-COLLAB-002，唯一负责人 Codex /root，风险 L2；独立复核为用户授权的只读 Codex 实例。

## P0 基线与复用

复用现有 Node 后端、Workflow/Workbench、SQLite、工程材料 Exchange/Ledger/Governance Host、模拟 Adapter、WPF 控件、深浅色和DPAPI草稿存储。没有重写Runtime或引入WebView。原正式主库不迁移，旧客户端和web保留。

备份见 evidence/offline-collab-002/baseline.json，代码差异见同目录 changed-files.json。所有功能测试仍只用虚构项目；用户后来授权的真实材料canary另列 TRB-REAL-MATERIAL-CANARY-001，不计入离线测试。

## P1 自然语言协作

实现的有界入口：明确Agent定向聊天、文字任务、总结请求、所选原文的独立/正式文字审查、只读任务/协作计划状态查询。常见礼貌词和DSH/DeepSeek Harness别名归一；引用、代码和普通名字提及不能触发路由。

新增持久计划：一个负责人完成文字任务后，将其当前版本原始结果交给一名独立复核者。首次只排负责人任务；有效来源回执后才创建一次复核；排除者不收到消息。计划和两阶段预算保存在既有SQLite，不依赖浏览器内存；重启不会丢掉依赖。UNKNOWN不重投，修改版本、资料授权撤销或身份变化会安全停止；需要修改时不擅自循环返工。复核通过不产生用户实施授权。

不支持的任意条件分支、多负责人、多轮自动返工等明确不执行。歧义只问必要问题，不新增复杂配置表单。纯聊天不凭关键词假装推断完整风险等级。

## P2 治理入口保护

治理完整性校验不仅在自然语言接口，还在公共创建/修订/授权及实际调度入口执行。普通文字分工只有一个真实负责人，复核者独立且不能审自己的原文；交叉列表和后续修订也保留来源。已登记工程任务及其子事项不能经普通文字审批绕过原Governance Host、准确Artifact、Issue和轮次规则。

正式工程流程继续区分L0-L3、P0/P1阻断与P2/P3建议；不把“所有文字消息”自动提升为工程审批。未关联普通文本无法自动证明其与某个工程Task相同，这是明确的语义能力边界。

本轮独立复核P1-COLLAB-ENTRY-001针对“已知消息来源被旧UI/API丢弃”，不是靠正文相似度猜测。修复让后端从真实sourceMessageId派生项目/事项/作者，冻结来源ID/作者/正文hash，纳入新审查快照；不允许通过修订或交叉复核洗掉来源。旧快照不补字段、不改旧hash。全部指定无条件通过及用户授权分离保护保留。

治理失败返回当前要求、具体规则、后果及替代方案并写SQLite审计；失败不清输入框。规则异常仍允许只暂停/取消，不能混入恢复或材料修改。

## P3 原生工作台

新增独立 runtime/native/TriReviewBridge.UX.Collab.exe，复用原生WPF三栏主工作台和深浅色。计划状态/暂停/UNKNOWN/需要人工介入及治理提醒在上下文呈现；面板折叠时重要异常仍能发现。后台仍是唯一业务状态来源。

修复新建窗口导航先后次序及重复Tree选择事件，防止新旧范围和草稿串线。保留多窗口、回复/引用/转交、材料、审批、技术详情等入口，不移除旧后端能力。

启动入口见OPERATIONS.md，使用data/collab-002-preview和48736，模拟绑定；不会切换主平台、清理旧数据或恢复任何原生投递。仅有启动器准备验证不等于运行耐久通过。

## P4 验证状态读取原则

以最新 evidence/offline-collab-002/verification.json 和最终测试/独立复核/soak报告为准。早期183/188测试记录、30秒烟测、首轮未通过材料都保留，不能冒充最终版本验收。一小时必须真实跑满当前源码和当前构建；Node和WPF心跳分别核对，不用加速时钟替代。

WPF图像是本程序 RenderTargetBitmap 渲染预览，不是桌面截图。没有首次使用者观察或实际125%/150%DPI证明时明确写未验证。

## 回滚

当前只影响独立候选和虚构数据库。最短回退是停止新候选，使用保留的旧exe和原隔离数据。代码恢复按baseline映射在新的隔离副本进行；新版新增C#文件须一并移入回退备份隔离，避免旧源码通配编译误混新文件。保留所有新证据，不直接删除未知文件；不要把含未完成计划的新库交给旧调度器继续处理。任何主版本升级或真实持续运行接管另作明确决定。
