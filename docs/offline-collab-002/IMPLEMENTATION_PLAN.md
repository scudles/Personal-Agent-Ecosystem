## 验收清单

- 自然语言独立安排负责人/复核者，排除者不收到消息；未提供持久Host时不伪造执行。
- 只有负责人已核对的当前版本模拟回执到达后才创建一次复核；不提前投递、不自动返工、不产生实施授权。
- 不完整独立意见不能被摘要/转交泄露；引用和代码中的@不改变接收范围。
- 已登记工程事项的后续动作不能经普通文字入口绕过治理；P2/P3不阻断，P0/P1及必要证据缺失阻断。
- 治理失败提醒保留要求/条款/影响/替代方案；失败不清用户草稿；未知自然语义不宣称已可靠判定风险。
- 重启保留全局与各Agent暂停；UNKNOWN不重发；迟到回执只能核对原投递；撤销资料授权安全停止。
- 原生WPF多会话草稿隔离/主题切换/项目导航/后端异常与恢复正常；不采用WebView。
- 一小时使用实际墙钟及单调时钟，Node和WPF各有心跳；同一WPF进程跨后台故障存活、草稿保留。六轮材料共18份逐文件核对；共27次模拟提交，不提高30/小时上限。
- 主平台配置、原桌面文件、45项受保护材料与历史档案核对；三条原生绑定仍暂停，主库不迁移。

## 明确限制

自然语言采用有界语法，不是开放域理解器。任意条件分支、多负责人、多轮自动返工等不在本次范围。无法仅凭普通未关联文字判断其是否属于既有工程任务；不能冒称已自动识别所有治理违规。正式工程审查仍使用已有可验证Artifact与Governance Host。
