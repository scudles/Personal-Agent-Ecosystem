# v1.0 分阶段实施计划

所有测试为虚构材料与模拟 Adapter。真实测试单独待用户授权，不能以本轮测试冒充完成。

| Phase | 实施与验证 | 回滚 |
|---|---|---|
| 0 | 停旧服务、备份、检查结构与41项基线、差异和风险 | 使用冻结副本；不恢复真实投递 |
| 1 | 多项目/Workspace、参与者与唯一绑定、复合外键；副本迁移/校验/恢复演练 | 新 workbench.sqlite 与旧库分离，停新服务即可保留旧库原样 |
| 2 | 显式路由、回复/转交、任务、完整审批快照、中央预算、取消和故障测试 | 新模式业务记录与旧库分离；保留新库备份 |
| 3 | WPF 原生 XAML，loopback 鉴权客户端；构建和启动自检 | 保留旧只读 Web 调试界面，不回退到真实 Adapter |
| 4 | Adapter 能力契约、默认真实硬锁、模拟身份/草稿/焦点/断线/重复保护 | 原 Adapter 源码保留，本轮不改原绑定、不激活 |
| 5 | 至少3项目×2 Workspace，全部有向线路模拟、故障、快照、重启/退出；交付说明 | 关闭桌面窗不终止后台；显式排空停止；备份新数据库 |

本机缺 .NET SDK，优先使用已有 .NET Framework 编译器构建真正 WPF；如不足再评估 D 盘 SDK，不改变产品原则。

每阶段报告列出实际运行、代码检查、模拟验证及未验证项。无授权的真实线路30次往返始终保留为未执行。
