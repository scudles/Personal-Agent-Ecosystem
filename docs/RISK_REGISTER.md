# 风险与证据边界

- R1 跨项目数据关联：复合外键 + 中央 scope 校验 + 反向越权测试。
- R2 旧未知投递误恢复：历史冻结；旧库不修改；真实 Adapter 不装配。
- R3 引用 @ / JSON 被当指令：只用元数据路由，正式 Agent 动作必须有父事项和绑定来源。
- R4 条件或快照变化误通过：不可变全快照；新版本清空票；user_authorization 独立。
- R5 循环与预算旁路：根事项累计预算，所有创建/发送/派生入口集中检查。
- R6 关闭窗重复投递：桌面只断开客户端；显式后端停止排空；重启对 SENDING/WAITING 标 UNKNOWN，不自动重发。
- R7 假在线：模拟、未绑定、历史真实锁定明确区分。
- R8 原生桌面真实可靠性：仅测试故障模拟与能力契约，未获准真实30往返，不声明真实稳定。
- R9 WPF兼容：本机编译、XAML加载、自检可验证；人工交互体验单列待验证，不以无报错冒充人工验收。
- R10 loopback凭据：仅本机、令牌恒时比较、Origin/Host校验、不得写进报告或截图；首版评估HTTP复用，Named Pipes后续可替换传输。
